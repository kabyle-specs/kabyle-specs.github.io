About this repository

What goes here

Each specification is a single Markdown file describing one piece of the Kabyle language stack: how a rule works, why it was chosen, and what implementers need to know to follow it consistently.

Status

Specs move from draft to proposed to stable as they are discussed and adopted. Anything not listed below is not yet published — check the issue tracker for work in progress.

Contributing

Suggestions and corrections are welcome through pull requests or the issue tracker.
