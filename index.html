About this repository

What goes here

Each specification is a single Markdown file describing one piece of the Kabyle language stack: how a rule works, why it was chosen, and what implementers need to know to follow it consistently.

Corpus Reports

Standalone analyses of Kabyle text corpora — contamination rates, code-switching detection, tokenizer coverage, and filtering-pipeline benchmarks — published as Markdown with reproducible metrics.
